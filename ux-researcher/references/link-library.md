# Link library

Curated external resources, mapped to the mode they serve. These were provided by Manon as trusted starting points. Surface a specific link only when it adds something the response does not already cover; do not dump the list. Link content and URLs change over time, so verify a page still says what you claim before citing it.

Annotations describe each resource by its evident topic. They are not summaries of the full contents.

## Interview questions and how to ask them (Modes 2, 3)

- Stephanie Walter, cheatsheet for user interview and follow-up questions
  https://stephaniewalter.design/blog/a-cheatsheet-for-user-interview-and-follow-ups-questions/
  Ready-to-use interview and probe questions. Good companion to the question bank and for follow-up technique.

- Stephanie Walter, the expert guide to user interviews
  https://stephaniewalter.design/blog/the-expert-guide-to-user-interviews/
  End-to-end interview practice: planning, running, probing. Supports Modes 2 and 4.

- User Interviews field guide, user research questions
  https://www.userinterviews.com/ux-research-field-guide-chapter/user-research-questions
  Structured chapter on writing research questions and study questions. Supports Modes 1 and 2.

- Katie Riley, how to ask good questions and level up your user research
  https://medium.com/@katierileyco/how-to-ask-good-questions-and-level-up-your-user-research-skills-19fd28b275a4
  Practitioner take on question quality and neutrality. Supports Modes 2 and 3.

- Interaction Design Foundation, common UX research interview questions
  https://ixdf.org/literature/article/common-ux-research-interview-questions
  Reference list of common interview questions. Useful as a starting menu for Mode 2.

- Userpilot, user research questions
  https://userpilot.com/blog/user-research-questions/
  Question examples grouped by research goal, product-oriented. Supports Mode 2.

- Reddit r/UXDesign, best user interview questions thread
  https://www.reddit.com/r/UXDesign/comments/1gcdbhy/what_are_the_best_user_interview_questions_that/
  Community discussion. Treat as practitioner anecdote, not authority. Useful for sense-checking phrasing against how working researchers actually ask.

## Bias and question neutrality (Mode 3)

- Stephanie Walter, 60 UX cards to discover cognitive biases
  https://stephaniewalter.design/blog/60-ux-cards-to-discover-cognitive-biases/
  Bias card deck. Useful for the bias taxonomy and for workshops on recognizing bias in questions and analysis.

## Method selection and study design (Mode 1)

- Stephanie Walter, solving design problems, finding UX tools, methods, and activities
  https://stephaniewalter.design/blog/solving-design-problems-finding-ux-tools-methods-activities/
  Helps map a problem to a method or activity. Direct support for Mode 1.

- Stephanie Walter, improving user experience with diary studies
  https://stephaniewalter.design/blog/improving-user-experience-with-diary-studies/
  Deep dive on when and how to run diary studies. Use when Mode 1 points toward longitudinal, in-context behavior.

## Adding to this library

Keep entries grouped by mode. For each new link record: title, URL, one line on what it is good for, and which mode it serves. Prefer primary sources (researchers, established UX organizations) over aggregators. Re-check links periodically; remove dead ones.
